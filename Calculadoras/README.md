# Calculadora em Python (Relax Day Project)

Estes projetos foram desenvolvidos em dias de descanso com objetivo de relaxar e praticar um pouco de lógica.

### Evolução do Projeto

* **Versão 2 (`calc_v2.py`):** Reescrevi o minha `calc_v1.py`, aplicando conhecimentos de POO (Programação Orientada a Objetos) e Tratamento de Exceções.
